# Canvas Visibility

Canvas Visibility는 복잡한 Obsidian Canvas를 더 읽기 쉽게 정리하고, 카드 내용을 흐름을 끊지 않고 편집할 수 있게 하는 플러그인입니다. 텍스트 카드와 마크다운 파일 카드를 제목 중심으로 접어 화면의 밀도를 낮추고, 필요한 카드는 이동·크기 조절이 가능한 Live Preview 편집기에서 바로 엽니다.

## 무엇을 할 수 있나요?

- **카드별 접기** — 텍스트 카드와 마크다운 파일 카드를 개별적으로 접거나 펼칩니다. 카드의 원본 `.canvas` 내용에 접기 상태나 제목을 기록하지 않습니다.
- **접힘 상태 크기 유지** — 가로 폭은 접기·펼치기 상태에서 공유하고 오른쪽 가로 전용 손잡이로 조절합니다. 접힌 카드의 세로 높이는 제목·부제·설명이 모두 보이는 최소 높이로 자동 정리되며, 펼친 카드의 세로 높이는 별도로 기억합니다.
- **Canvas 도구 모음 버튼** — 카드 하나를 선택하면 상단 Canvas 도구 모음에서 접기 버튼과 그 바로 옆 빠른 편집기 버튼을 사용할 수 있습니다.
- **접힌 카드 요약** — 텍스트·마크다운 파일 카드의 접기 설정 시 제목, 부제와 설명을 입력할 수 있으며, 접은 뒤에도 카드의 `A` 버튼에서 세 문구와 표시 스타일을 다시 수정할 수 있습니다. 부제·설명은 접힌 카드에서만 제목 아래에 표시됩니다.
- **제목 중심 탐색** — 텍스트 카드는 카드의 첫 제목 또는 내용 줄을 미리 제목으로 제안하며, 사용자가 원하는 제목으로 바꿀 수 있습니다. 파일 카드는 파일명을 제목으로 표시하고, 카드마다 제목 크기를 12–200px 범위에서 조정할 수 있습니다.
- **헤더 스타일** — 카드별로 접힌 제목의 글자색과 헤더 배경색을 지정하거나 기본 테마 색상으로 되돌릴 수 있습니다.
- **Canvas를 흐트러뜨리지 않는 조작** — 접힌 카드의 제목 영역으로 카드를 드래그해 이동할 수 있으며, 큰 제목에도 알맞은 최소 높이를 자동으로 확보합니다.
- **빠른 Live Preview 편집** — 선택한 텍스트·마크다운 파일 카드를 떠 있는 편집기에서 편집합니다. 실제 Obsidian `MarkdownView`를 사용하므로 링크, 이미지, 문법 및 설치된 플러그인 확장을 그대로 활용합니다.
- **다중 편집과 창 접기** — 여러 카드의 빠른 편집기를 동시에 열고, 각 창을 제목줄만 남기도록 접었다가 이전 높이로 펼칠 수 있습니다.
- **제목에서 바로 편집** — 접힌 카드의 제목을 더블클릭하면 빠른 편집기가 열립니다.
- **가벼운 열기 전환** — 빠른 편집기는 레이아웃 계산 없이 `opacity`와 `transform`만 사용하는 짧은 페이드·확대 전환으로 나타납니다.
- **작업 환경 기억** — 빠른 편집기의 위치와 크기를 저장하고, 명령어·컨텍스트 메뉴·설정에서 주요 기능에 접근합니다.

## v0.7 기능

- Canvas 텍스트 카드와 마크다운 파일 카드의 선택적 접기
- 접기 헤더와 본문이 겹치지 않는 레이아웃
- 헤더 제목 영역을 이용한 접힌 카드 이동
- 선택한 카드마다 12–200px 제목 크기 지정
- 제목 크기에 맞춘 접힌 카드 최소 높이 자동 보정
- 마크다운 파일 카드 제목으로 파일명 사용
- 텍스트 카드의 사용자 지정 제목과 첫 내용 줄 대체값
- 접힌 카드 설정에서 기존 제목·부제·설명과 표시 스타일 다시 수정
- Obsidian의 실제 MarkdownView를 사용해 문법, 링크, 이미지, 플러그인 확장을 그대로 지원하는 Live Preview
- 이동 및 크기 조절이 가능하고 마지막 위치를 기억하는 빠른 편집기
- 한글 설정, 명령어, 메뉴, 버튼, 상태 및 오류 문구

## 사용 방법

1. Canvas에서 텍스트 카드 또는 마크다운 파일 카드를 선택합니다.
2. 카드 컨텍스트 메뉴에서 **카드 접기 사용**을 선택하거나 명령 팔레트에서 **선택한 카드에 접기 사용**을 실행합니다.
3. 접힌 카드의 화살표로 접기/펼치기를 전환하고, 제목 영역을 드래그해 카드를 옮깁니다.
4. 카드를 하나 선택한 뒤 접기 버튼 옆 **빠른 편집기로 열기** 버튼을 누르거나 Enter를 눌러 내용을 Live Preview에서 수정합니다.

명령 팔레트에서는 선택 카드의 접기 사용·해제·전환, 현재 Canvas의 접기 사용 카드 전체 접기·펼치기·전환, 빠른 편집기 열기를 제공합니다.

## 구현 참고

Obsidian은 Canvas 런타임 노드를 안정적인 공개 API로 제공하지 않습니다. 관련 접근은 `src/canvas/canvas-adapter.ts`에 격리했습니다.

빠른 편집기는 [Hover Editor](https://github.com/nothingislost/obsidian-hover-editor)의 구조를 참고해, 떠 있는 창 내부에 실제 Obsidian `WorkspaceLeaf`와 `MarkdownView`를 연결합니다. 따라서 별도의 마크다운 모조 렌더러가 아니라 Obsidian 편집기와 동일한 Live Preview를 사용합니다.

## 빌드

```powershell
pnpm install
pnpm build
pnpm verify
```

`main.js`, `manifest.json`, `styles.css`를 다음 경로에 복사한 뒤 Obsidian에서 플러그인을 활성화합니다.

```text
<vault>/.obsidian/plugins/canvas-visibility/
```

BRAT에서는 다음 공개 저장소를 추가합니다.

```text
tlatndms2-droid/obsidian-canvas-visibility
```
