# Canvas Image Copy

Windows용 Obsidian 플러그인입니다. Canvas에서 선택한 이미지 파일 여러 개를 실제 파일 클립보드로 복사하거나 원하는 폴더에 저장합니다.

## 설치

Obsidian 1.12.7 이상과 Windows가 필요합니다.

BRAT 설정에서 **Add Beta plugin**을 선택하고 `tlatndms2-droid/canvas-image-copy`를 입력한 뒤, 커뮤니티 플러그인에서 **Canvas Image Copy**를 활성화하세요.

## 사용

1. Canvas에 직접 놓은 이미지 카드를 여러 개 선택합니다.
2. 선택한 카드 위에서 우클릭합니다. 명령 팔레트에서 `Canvas Image Copy`를 검색해도 됩니다.
3. 아래 기능 중 하나를 실행합니다.

| 기능 | 결과 |
|---|---|
| 선택한 이미지를 클립보드에 복사 | Windows 탐색기나 파일 붙여넣기를 지원하는 앱에서 Ctrl+V로 파일들을 붙여넣을 수 있습니다. |
| 선택한 이미지를 폴더에 저장… | Windows 폴더 선택 창에서 위치를 한 번 고르면 모든 이미지가 그곳에 저장됩니다. |

원본 이름과 확장자를 유지합니다. 대상 폴더에 같은 이름이 있으면 `사진 (1).png`처럼 번호를 붙이며 기존 파일을 덮어쓰지 않습니다. 폴더 선택 창에서 취소하면 저장하지 않습니다.

같은 원본 파일을 가리키는 카드를 여러 개 선택해도 파일은 한 번만 처리합니다. 텍스트·노트·링크·그룹 카드는 제외하고 알림에 제외 개수를 표시합니다. 원본 파일과 Canvas 배치는 변경하지 않습니다.

지원 확장자: PNG, JPG/JPEG, GIF, WebP, AVIF, BMP, SVG. 그룹 배경, 노트 내부 이미지, 외부 URL 이미지는 대상이 아닙니다. 클립보드는 파일 참조 방식이므로 붙여넣기 전에 원본을 삭제하거나 이동하지 마세요. 붙여넣기 지원 여부는 대상 앱에 따라 다릅니다.

## 개발

Node.js 22.18 이상에서 의존성을 설치하고 빌드합니다.

```sh
npm install
npm test
npm run build
```

빌드 결과 `main.js`와 `manifest.json`을 플러그인 폴더에 함께 넣습니다. Windows PowerShell의 표준 파일 클립보드 기능을 사용하며 별도의 실행 창은 표시하지 않습니다. 폴더 저장은 파일을 변환하지 않고 그대로 복사합니다.

## 검증 범위

0.1.0은 격리된 Sandbox에서 실제 Canvas 선택·우클릭·명령 팔레트, Windows 파일 클립보드, 기본 폴더 선택 창을 통한 저장, 파일명 충돌, 취소, Obsidian 재시작을 확인했습니다. 최초 실행은 Obsidian 1.12.7, 재시작 후 실행은 1.13.7입니다.

BRAT 설치·활성화와 Release 업로드 후 자산 재다운로드 검증은 수행하지 않았습니다.
