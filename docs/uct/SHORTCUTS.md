# UCT 0.1.1 — 단축키·명령

| 화면 | 조작 | 결과 |
|---|---|---|
| Canvas 선택 카드 | Alt+L | 라벨 직접 생성/이름 편집 |
| Canvas 라벨 | 더블클릭 | 이름·색상 작은 편집 영역 |
| Canvas 선택 카드 | Alt+C | 캡션 직접 생성/편집 |
| Canvas 캡션 | 더블클릭 | 기존 내용 편집 |
| 라벨·캡션 입력 | Enter / 바깥 클릭 / Esc | 저장 / 저장 / 취소 |
| Canvas 텍스트·Markdown | Enter | 빠른 편집기, Esc 저장·닫기 |
| Canvas PDF | Enter / Shift+Enter | 읽기 / 큰 미리보기 |
| Canvas Portal | Ctrl+Enter | 진입·복귀 |
| Mini 항목 | 클릭 / 더블클릭 | 상세 / 큰 미리보기 |
| Mini 항목 | Ctrl·Shift 클릭 | 기존 복수 선택 |
| Mini → Canvas | 드래그 / Shift 드래그 | 이동 / 복사 |
| 배치 오버레이 | Esc | 취소, 원본 Mini 유지 |
| Mini 이름 변경 창 | Enter / 저장 | 표시 이름 저장, 원본 파일명 유지 |

명령 팔레트에서 **Mini Palette 열기/닫기**와 기존 발표 켜기/끄기·PT Vision·이전/다음·항목 추가를 사용합니다. 새 **PT 그룹만 선택 켜기/끄기**, **드래그 영역 만들기**, **현재 화면 영역 만들기**, **발표 List / Map 전환**에는 기본 단축키가 없습니다. Obsidian 설정 → 단축키에서 직접 지정합니다. Waypoint 전용 명령·단축키는 제거했습니다. 사용자 지정 키가 이 문서의 기본 키보다 우선합니다.
