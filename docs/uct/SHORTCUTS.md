## 로컬 0.1.5 추가

- Ctrl+Shift+Enter: Canvas 카드/MD 카드/일반 Markdown 컴포지션 모드.
- Esc: 컴포지션은 저장 후 원래 화면, 작은 편집기는 현재 창만 저장·닫기, 미디어는 재생 중지·닫기.
- Enter: 기존 작은 편집기. Ctrl+Enter: 포탈 입장·퇴장.

## 로컬 0.1.6 추가 확인
- Canvas 이미지·영상·음악 카드: Shift+Enter → 공통 전체 화면 미리보기. PDF는 기존 Shift+Enter 유지.
- Canvas 이미지의 기존 Enter도 같은 이미지 미리보기 사용.
- Storage 경계: 좌우 드래그, 경계에 키보드 포커스 후 좌우 방향키로 10px 조절.


## 로컬0.1.10 입력 우선순위

- 색상 팔레트가 열려 있으면 방향키·Enter는 색 선택에 사용되고 Canvas 카드 이동으로 전달되지 않습니다.
- 컴포지션에서 Ctrl+Z는 본문 실행 취소, Ctrl+Y/Ctrl+Shift+Z는 본문 다시 실행입니다. 본문 서식/클립보드/우클릭은 유지합니다.
- 컴포지션 밖의 UI 명령은 작성 중 차단하고 종료 후 복구합니다. Esc와 Ctrl+Shift+Enter로 원래 화면에 돌아옵니다.
