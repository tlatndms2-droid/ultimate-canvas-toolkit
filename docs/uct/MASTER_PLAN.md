# Ultimate Canvas Toolkit — 확정 범위

2026-10-26. 사용자 결정 완료 후 전체 구현·실제 앱 검증·공개 배포를 승인받았다. 상세 결정은 [DECISIONS.md](DECISIONS.md), 실제 진행 상태는 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)를 따른다. 이 범위에 나중에 정할 사용자 동작은 남기지 않는다.

## 통합 기능

- Mindmap: 기존 카드 생성·연결·해제·방향·탐색·정렬·크기·선택 이력·파일 삽입·색상·미디어 기능을 재사용한다.
- Portal: 가상 포탈과 실제 다른 Canvas의 링크 포탈, 중첩·복제·이동·해제·복귀·Undo·저장 안전 기능을 유지한다.
- Outliner: 기존 등록·그룹·Collection·발표·Vision·Remote 기능을 유지한다. 현재 Portal 공간만 표시하고, 안쪽 Portal은 진입 전에는 항목으로만 보인다. 라벨 있는 항목을 자동 표시하며 라벨·캡션은 확인 전용이다. Canvas Search에 라벨을 포함한다.
- Visibility: Enter 빠른 텍스트/Markdown 편집기만 사용한다. 접기 모듈·전용 타이머·접기 UI는 실행하지 않는다.
- PDF Viewcard: 기존 카드 읽기·페이지·배율·레이아웃·공유 문서 pool을 유지한다. 큰 보기는 Shift+Enter이며 Ctrl+Enter Portal 동작과 겹치지 않는다.
- Image Copy: 선택 이미지 파일의 Windows 클립보드·폴더 내보내기를 유지한다. Canvas 화면 캡처 기능이 아니다.
- Palette: Mini와 Canvas 라벨·캡션·앞뒷면·하이라이트 기반을 유지한다. 구형 Side/Workspace 진입점과 태그 UI는 제거한다.

## 공통 공간과 입력

파일 경로 + 포탈 ID로 공간을 구분한다. Outliner·metadata·PDF·편집기·Mindmap 출발점이 현재 공간을 공유한다. Waypoint 기능은 제거하고 과거 저장 기록만 보존한다. Alt+L은 카드 위 라벨 직접 입력, Alt+C와 카드 아래 hover ＋는 캡션 입력이다. 입력창·IME 중에는 단축키를 중복 실행하지 않는다.

## Mini

화이트 갤러리, 카드/목록, 접을 수 있는 Storage, Collect, 사용자 폴더·하위 폴더, 폴더와 무관한 형식별 보기, 선택 시에만 나오는 상세 패널을 사용한다. 상세에는 큰 미리보기·수집일·수정일·수집 위치·라벨·캡션이 보인다.

기존 수집·잘라내기·삭제·Ctrl/Shift 선택·정렬·묶음 직렬화를 재사용한다. Collect→폴더는 이동이다. 일반 드래그는 배치 성공 후 Mini에서 제거하고 Shift 드래그는 사본을 배치하고 유지한다. 오버레이로 위치를 정하며 Esc는 취소한다. 별도 자료는 서로 겹치지 않고 기존 묶음 안의 좌표·연결은 유지한다. 저장 실패 시 원래 Canvas와 Mini 자료를 보존한다.

검색은 현재 목록이며 전체 검색으로 전환할 수 있다. 전체 결과에 폴더 경로를 보인다. 폴더 삭제는 직접 자료를 미분류로 보내고 하위 폴더를 미분류 아래로 옮겨 구조를 유지한다.

일반 파일 항목은 원본 경로를 유지하고 이름·위치 변경을 따라간다. 원본 파일 삭제 시 해당 Mini 항목을 제거한다. Canvas 카드 삭제·잘라내기는 해당하지 않는다. 링크 Portal은 내부 Canvas와 필요한 로컬 파일의 독립 사본으로 보관한다. 일반 항목과 원본 내용을 계속 동기화하지 않는다.

Workspace 이름을 새 최상위 폴더로 옮기고 하위 구조·직접 항목을 유지한다. Collect는 유지하고 원본 저장 파일은 수정하지 않는다. 폴더 순서는 보존하고 새 폴더는 뒤에 추가한다.

## 백업

수동 ZIP만 제공한다. 매번 저장 위치를 고르며 필요한 파일도 포함한다. 복구는 새 복구 폴더에 Collect와 하위 폴더·새 항목을 만들어 추가한다. 기존 항목·파일을 덮어쓰지 않는다. 과거 시점 10개 유지나 자동 Mini 백업을 추가하지 않는다. Portal 자체 안전 백업은 별개로 유지한다.
