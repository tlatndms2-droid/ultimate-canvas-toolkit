# UCT 로컬 0.1.11 후속 통합 검증

2026-10-28. 공개 배포·push·Release·BRAT 미실행. 기존 Sandbox/Profile 사용. 전체 최종 통합 검증은 아직 완료 판정하지 않음.

## 이번 수정
- Obsidian 창을 줄일 때 열린 Mini가 화면 밖으로 벗어나는 문제 수정. 목록을 다시 생성하지 않고 패널 폭·높이·위치를 화면 경계 안으로 조정.
- Mini 목록의 분리 DOM 구성 실험은 측정 편차와 결과 불일치로 되돌림. 속도 개선으로 보고하지 않음.

## 성능 수치와 판정
3회 동기 render/search 경과 ms. 같은 자료 규모로 측정했으나 실행별 편차가 큼. 사용자에게 보이는 전체 렌더 완료 시간으로 해석하지 않는다.

## 남아 있는 범위
- 큰 자료에서 Mini 반응 지연의 안정적인 원인 분리·개선 검증.
- 최종 빌드의 긴 Markdown 입력·저장 비용, 반복 사용 메모리 회수와 남은 템플릿 옵션 전체 조합 확인.
- 이미지 내보내기의 실제 Windows 폴더 선택 UI.
- 앞선 감사 기록의 통과 항목과 이번 증거를 합친 전체 완료표. 이번에 다시 실행하지 않은 과거 검증을 새 통과로 표시하지 않는다.
- PDF 주석·메모, 배포, 실제 작업 Vault 변경, 원본 저장소 삭제는 제외.
