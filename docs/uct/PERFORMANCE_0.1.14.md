# UCT 0.1.14 성능 개선 결과 — 2026-10-29

## 적용한 변경
- Palette 저장: 별도 library에 저장되는 items/workspaces/collections를 복제 대상에서 먼저 제외. 기존 저장 JSON과 완전히 동일하고 원본 객체를 변경하지 않음.
- Canvas 캡션: Mini/설정/Outliner DOM 변경으로 Canvas 전체 검사를 예약하지 않음. Canvas 카드 추가 및 내용 변경, 포탈 전환은 유지.
- 발표: 매 프레임 전체 카드 좌표 배열을 만들고 문자열로 변환하는 작업을 snapshot 교체 식별로 대체. viewport 투영은 기존 프레임 주기 유지.
- Mini: Storage 토글은 기존 카드/미리보기 DOM을 유지. 형식 개수 집계는 자료당 한 번.
- 컴포지션: input/editor-change의 글자 수 및 타자기 스크롤 갱신을 프레임당 한 번으로 병합. 종료 시 예약 해제.

## 측정
| 범위 | 이전 | 변경 후 | 조건 |
|---|---:|---:|---|
| 발표 render 1,000회 중앙값 | 549.6ms | 80.8ms | 514개 카드, 동일 실행 환경, 5회. 이전 좌표 배열 생성 경로를 임시 accessor로 재현한 함수 수준 A/B |
| 저장 전 복제 중앙값 | 60.0ms | 0.2ms | 합성 500개 묶음/15,000노드, 5회, 결과 JSON 일치 |
| Mini render 4회가 유발한 캡션 검사 | 7회 | 0회 | 기존 실제 Collect 12항목. 이전 7회 총32.1ms; 개선 후 최종빌드 |
| Storage 토글 카드 DOM | 재생성 | 동일 객체 유지 | 실제 UI 클릭 및 객체 동일성 확인 |

위 수치는 전체 플러그인 개선율, 전체 저장 시간, 사용자 체감 시간으로 일반화하지 않음.
5초 idle 실험은 다른 UI 작업/시스템 부하의 영향으로 편차가 컸음. 514카드 개선 후153.2ms 중앙값 대 이전224.1ms이지만 엄격한 전체 CPU 비교로 사용하지 않음. 33카드에서는 일관된 개선을 입증하지 못함.

## 검증
- 타입 검사 및 빌드 통과. 24개 테스트 통과.
- Palette 저장 JSON/원본 불변, 제외 그래프 미순회 회귀 검사 추가.
- Sandbox 실제 Storage 펼침/접힘 화면 확인. 카드/썸네일 유지.
- Alt+C 캡션 생성, 저장 후 + 숨김 유지.
- 발표 2항목 등록/진입/다음 항목 선택/종료.
- 카드 좌표 변경 시 snapshot/발표 revision 갱신 및 원위치 복구.
- 가상 포탈 Ctrl+Enter 진입/복귀, 내부 일반카드3개에 캡션 버튼3개.
- 44,011자 문서 입력/글자 수 일치/자동 저장/Esc 종료.
- 같은 격리 Sandbox 재시작 후 활성0.1.14, Mini51항목, Storage 상태 및 캡션 유지.
- 소스/설치 main.js, manifest.json, styles.css SHA256 일치. 관찰 중 pageerror 없음.
- 실제 화면은 CDP/Playwright로 확인. Windows 포인터 Computer Use는 이번 검증에 사용하지 않음.

## 범위와 남은 측정
이번 변경 관련 검증 통과이며 모든 기능 종합 감사 완료는 아님.
PDF/Portal idle 비용은 기존 측정에서 작아 변경하지 않았음. 대용량 미디어 표지 읽기, 대규모 ZIP 메모리, 장시간 메모리 회수, 실제 Secondbrain 전체 CPU/메모리 전후 비교는 미검증. Mindmap 100ms 폴링은 유지.
사용 흐름/저장 형식/썸네일 품질을 변경하지 않음. 실제 Secondbrain Vault와 원본7개 저장소는 변경하지 않음.
