# 사용자 확인 체크리스트

Codex 검증: 격리 Obsidian 1.14.5에서 Portal 공간 전환, 라벨·캡션·Canvas Search, Enter 편집/닫기, Shift+Enter PDF, Mini 드래그 이동·Shift 복사·취소·실패 복원, ZIP 복구, 실제 앱 재시작을 확인했습니다. 실제 작업 Vault는 변경하지 않았습니다.

- [ ] BRAT에 `tlatndms2-droid/ultimate-canvas-toolkit`을 추가하고 기존 7개 플러그인은 끈 뒤 UCT를 켭니다. 기대 결과: UCT 0.1.0 한 개로 기능이 열립니다.
- [ ] Portal에 들어갔다 나옵니다. 기대 결과: Outliner가 현재 공간만 표시하고, 라벨·캡션과 검색 결과가 해당 공간에 맞습니다.
- [ ] Mini 자료를 드래그한 다음 Shift를 누르고 다시 드래그합니다. 기대 결과: 일반 배치 성공 후 Mini에서 빠지고, Shift 복사는 Mini에도 남습니다. Esc 취소 시 자료가 유지됩니다.
- [ ] Storage 폴더를 만들고 자료를 옮긴 뒤 폴더를 삭제합니다. 기대 결과: 직접 자료와 하위 폴더가 미분류로 옮겨지고 하위 구조는 유지됩니다.
- [ ] 백업 ZIP을 저장한 뒤 복구합니다. 기대 결과: 위치를 직접 고르며, 기존 자료와 별개인 복구 폴더가 생깁니다.

일반 파일 원본 삭제는 해당 Mini 항목 삭제로 이어집니다. 링크 Portal 독립 보관본은 원본 Canvas 삭제 후에도 유지합니다. 실제 보관 자료로 삭제 시험을 할 필요는 없습니다.

원본 저장소는 사용자가 직접 “완성됐다”라고 말하기 전까지 삭제하지 않습니다.
