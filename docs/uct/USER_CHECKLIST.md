# UCT 0.1.1 사용자 확인표

Codex 확인 완료: 11개 테스트·TypeScript·빌드, 격리 Obsidian 1.14.5 실제 UI/동작·재시작, 공개 파일3개 대조, BRAT2.2.0으로0.1.1 설치·활성화. 항목·폴더·metadata·창 상태 보존을 확인했습니다. 아래는 사용자가 직접 살펴볼 항목입니다.

- [ ] BRAT에서 UCT를0.1.1로 업데이트합니다. 기대 결과: 기존 보관 자료가 남고, Waypoint 명령·배지와 Canvas metadata 버튼이 없습니다.
- [ ] 카드 선택 후 Alt+L로 라벨을 만들고 라벨을 더블클릭합니다. 기대 결과: 별도 큰 창 없이 이름을 입력하고 작은 영역에서 색상을 고릅니다. Alt+C/카드 아래 +는16px 간격의 캡션을 만듭니다. Enter·바깥 클릭은 저장, Esc는 취소입니다.
- [ ] Canvas Search에서 라벨을 선택해 검색하고 Portal을 오갑니다. 기대 결과: 현재 공간의 일치 라벨만 검색되며, Outliner의 일반·가상 포탈·링크 포탈 아이콘이 구분됩니다. 발표 기능은 명령 팔레트에서 실행합니다.
- [ ] Mini 항목을 한 번 클릭한 다음 더블클릭하고 우클릭 이름 변경을 사용합니다. 기대 결과: 상세 → 형식별 큰 미리보기, 새 이름 즉시 반영. 묶음은 배치·연결을 유지하며 원본 파일명은 그대로입니다.
- [ ] Storage와 폴더를 접고 창의 변·모서리를 끌어 크기를 바꾼 뒤 앱을 다시 엽니다. 기대 결과: 저장한 접힘·크기·위치와 보관 자료가 유지됩니다.

Mini→Canvas 일반 드래그는 성공 후 Mini에서 빠지는 이동, Shift 드래그는 보존하는 복사입니다. Esc로 취소하면 자료가 남습니다. 실제 작업 Vault와 원본7개 저장소는 변경하지 않았습니다. Sandbox는 검토할 수 있게 열어 두었습니다.
